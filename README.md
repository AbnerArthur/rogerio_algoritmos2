# rogerio_algoritmos2

Listas de exercícios da disciplina de Algoritmos 2 (IFMS), resolvidas em Python.

Cada lista fica em uma pasta própria e foi desenvolvida em uma branch separada.

| Lista | Assunto | Pasta |
|---|---|---|
| 1 | Funções e Listas | `Lista01_Funcoes_e_Listas` |
| 2 | Funções, Listas e Tuplas | `Lista02_Funcoes_Listas_e_Tuplas` |
| 3 | Vetor e Matriz | `Lista03_Vetor_e_Matriz` |
| 4 | Recursividade | `Lista04_Recursao` |

## Como executar

```
python Lista01_Funcoes_e_Listas/exercicio01.py
```

A Lista 3 usa NumPy: `python -m pip install numpy`
